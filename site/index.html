The problem

Estimating a feature is guesswork.

The landmines are only found by building, so they are found after the date is promised.

/01

Estimate

Engineers read the code and guess the size. "About two days."

/02

Build

Days in: a column too small, a query that gives wrong answers, a cache shared across customers.

/03

Slip

The date moves, and the team trusts its next estimate a little less.

2 days 2 weeks
How it works

One sentence in. Evidence out.

Bob investigates, Settle checks. On your repository, with your Bob, in about four minutes.

/01

Bob finds the risks

Bob reads the code the feature touches and names what must be true for it to be as easy as it looks.

/02

Bob runs experiments

One Bob per assumption, all at once, each in its own copy of your repo, writes a real test.

/03

Settle checks the work

Every experiment is rerun by Settle, not taken on Bob's word. Experiments may only add files.

/04

Bob plans from facts

The plan is written from what was found, with the landmines first.

Three lines to your first proof

Write the feature you are about to estimate in prove.yml, give Settle your IBM Bob Shell key, and run it. The evidence board and the plan arrive in about four minutes.

# in your app's git repo
echo 'request: Add team accounts' > prove.yml
export BOB_API_KEY=...   # Bob Shell, Inference scope
settle prove             # risks, experiments, evidence, plan
FAQ

Questions, answered.

Is this a chatbot?

No. You give it one sentence and it runs experiments. The output is tests that passed or failed against your code, the exact errors, and a plan written from them.

Why trust what Bob found?

You don't have to. Settle reruns every experiment itself, and any experiment that changes an existing file is marked untrusted. Each finding shows the rerun output, Bob's own read, and the test code.

Does it change my code?

No. Experiments run in separate git worktrees and may only add files. Nothing is merged; every experiment stays on its own branch for you to open or delete.

What does a proof cost?

The demo proof took about four minutes and about three Bobcoins: one Bob session to name the risks, one per assumption, and one to write the plan.

What if Bob picks the wrong risks?

The board shows exactly which assumptions were tested, so the team can challenge them. Settle proves or disproves what it tests; it does not claim to find every risk.
